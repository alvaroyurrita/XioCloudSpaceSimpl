# XIO Cloud Space SIMPL

This is a sample project that demonstrates the use of XIO Cloud Slot-15 Module in SIMPL.

It demonstrates the different submodules for the XIO Cloud Slot-15 Module in SIMPL.

* XIO Cloud Space Meta Data
* Volume
* Scheduling
* Call
* Lighting
* Shades
* Climate
* Quick Action

More information on the module can be found in the [SIMPL Official Documentation](https://help.crestron.com/simpl/#Device_Library/Control_Systems/4-Series%20XiO%20Room/Cloud-Space/XiO-Cloud-Space.htm?TocPath=Device%2520Library%257CControl%2520Systems%257CCP4%257CSlot-15%253A%2520XiO%2520Cloud%2520Space%257C_____0)

This program was created for a CP4 control system.

For more information on the XiO Cloud Connector consult the [Official Documentation](https://docs.crestron.com/en-us/8214/Content/Topics/Program-Connector.htm?Highlight=xio%20cloud%20space)

## Web Xpanel

This program works in tandem with the [Web Xpanel](https://github.com/alvaroyurrita/XioCloudSpaceConstruct). If you want to store the web Xpanel in a CP4 and have it reference in XiO you will need to modify the web Xpanel address in module S-4.2 to point to your own CP4 FQDN.
